# 自主練習 · 小小商店

`自主練習（じしゅれんしゅう）` 是日语的“自主练习”。这是第 1–19 天知识的综合基础版，使用原生 HTML、CSS、JavaScript，不需要安装依赖。

## 运行

在项目根目录 `D:\VSCode\JS` 的终端运行：

```powershell
node server.cjs
```

浏览器打开 http://127.0.0.1:5173/自主練習/ 。也可以用 VS Code 的 Live Server 打开本文件夹的 `index.html`。直接双击 HTML 在部分浏览器也可使用，但推荐通过本地服务练习。

## 文件和阅读顺序

- `index.html`：页面结构、商品模板、购物车模板。
- `styles.css`：配色、布局、手机适配。
- `script.js`：按数据 → 本地保存 → 请求 → 筛选渲染 → 购物车 → 事件的顺序阅读。

## 已实现

- 用 `fetch` 获取商品，检查 HTTP 错误、数据格式和 10 秒超时。
- 搜索名称、描述和分类；中文分类也可以搜索，例如“香水”。接口返回的商品名称保留英文。
- 分类筛选与搜索同时生效，支持价格升序、降序、名称排序。
- 加入购物车；相同商品合并为一行。
- 加减数量，也可以直接输入 1–99 的整数；支持单件删除和清空。
- 用 `reduce` 计算数量与合计，以整数分计算金额。
- 用 `localStorage` 自动保存和恢复购物车；保存失败时显示提示。
- 加载中、接口空列表、无搜索结果、请求失败与重试状态。
- 手机屏幕改为上下布局，可通过顶部“购物车”直接跳转。

## 接口与边界

商品来自 [DummyJSON 官方商品接口](https://dummyjson.com/docs/products)：`https://dummyjson.com/products?limit=30`。基础版获取前 30 件商品，搜索、分类、排序都在这 30 件商品中执行。需要网络，无需 API key。金额按美元 USD 展示，无汇率转换。

这是交互练习，只计算商品金额；购物车保存在当前浏览器、当前网站地址下。浏览器清理站点数据会删除记录，换端口也不会共享记录。

## 手动自测

1. 刷新页面，确认加载提示消失，出现商品图片、名称和价格。
2. 搜索 `apple` 或 `香水`；再切换分类和价格排序，观察结果。
3. 输入 `zzzz-no-match`，确认出现空状态，点击“重置筛选”。
4. 同一商品加入两次，确认数量为 2，购物车中只有一行。
5. 加入另一件商品，修改数量，核对每行小计与总价。
6. 输入 `0`、`-1`、`1.5`、`100` 或清空数量输入框后移开焦点，确认提示并恢复原值。
7. 刷新页面，确认购物车恢复；删除商品和清空后再次刷新，确认结果保留。
8. 开发者工具 Network 选择 Offline，点击“重新加载”，确认错误提示；恢复网络后点击“重新尝试”。
9. Network 选择 Slow 3G 后重新加载，观察加载状态；超过 10 秒会超时。
10. 用设备模式切换到 375px 宽度，确认页面没有横向滚动，购物车位于商品列表下方。

## 练习建议

先操作页面，再按 `script.js` 中 1–6 段注释阅读代码。理解后合上参考代码，尝试独立重写“搜索”和“加入购物车”。
