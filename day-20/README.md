# Day 20：商品列表与购物车

使用 HTML、CSS 和 JavaScript 编写，不需要安装依赖。

## 1. 启动页面

在项目根目录 `D:\VSCode\JS` 打开终端：

```powershell
node server.cjs
```

浏览器打开：http://127.0.0.1:5173/day-20/

停止服务时在终端按 `Ctrl+C`。也可以使用 VS Code 的 Live Server 打开 `day-20/index.html`。

商品来自 DummyJSON：`https://dummyjson.com/products?limit=30`。需要网络，默认获取前 30 件商品。价格单位是美元，不进行汇率转换。

## 2. 文件说明

| 文件 | 内容 |
| --- | --- |
| `index.html` | 商品列表、购物车、状态提示 |
| `styles.css` | 页面布局、商品卡片、购物车样式、手机适配 |

## 3. 操作手顺

### 显示商品

1. 打开页面，观察加载提示。
2. 等待商品名称、图片和价格出现。
3. 点击“重新加载”，确认列表没有重复追加。
4. 如果加载失败，检查网络后点击“重新尝试”。

### 加入购物车

1. 选择一件商品，点击“加入购物车”。
2. 确认购物车显示该商品，数量为 1。
3. 再点击同一商品的“加入购物车”。
4. 确认购物车仍只有一条该商品记录，数量变为 2。
5. 加入另一种商品，确认新增一条记录。

### 修改数量

1. 在购物车中修改数量，按 Tab 或点击输入框外使修改生效。
2. 确认数量、小计、商品总数量和总价更新。
3. 分别输入 `0`、`-1`、`1.5`、`100`，或清空输入框。
4. 移开焦点后，确认显示提示并恢复原数量。

每种商品的数量范围为 1～99。数量为 99 时，再加入同一商品会显示上限提示。

### 删除和清空

1. 点击某件商品的“删除”。
2. 确认该商品消失，数量和总价重新计算。
3. 点击“清空购物车”。
4. 确认显示“购物车为空”，总数量和总价归零。

### 保存和恢复

1. 加入商品并修改数量。
2. 确认出现“购物车已保存”。
3. 刷新页面，确认商品和数量恢复。
4. 删除一件商品后刷新，确认被删除的商品没有恢复。
5. 清空购物车后刷新，确认仍为空。

## 4. 代码阅读顺序

### 购物车数据

`cart` 是数组，每个对象保存一种商品：

```js
let cart = [
  { id: 1, title: '示例商品', price: 2.5, quantity: 2 }
];
```

`addToCart(product)` 使用 `find()` 按 ID 查找商品。找到后修改 `quantity`，没有找到则使用 `push()` 新增记录。

数量输入使用 `change` 事件。在 `isValidQuantity()` 中用 `Number.isInteger()` 和范围判断检查输入。

删除商品时，使用 `filter()` 返回不包含该商品的新数组，再赋值给 `cart`。

### 更新页面和保存

每次修改后调用 `updateCart()`：

```text
修改 cart
  → renderCart() 更新页面
  → saveCart() 保存到浏览器
```

修改数组不会自动改变原生 HTML 页面，需要主动调用渲染函数。

### 金额计算

```text
小计 = 单价 × 数量
总价 = 所有商品的小计相加
```

代码中先把单价转换为整数“分”，再计算金额。例如：

```text
单价 2.50 美元，数量 3
250 分 × 3 = 750 分
显示金额：750 ÷ 100 = 7.50 美元
```

`reduce()` 的 `sum` 保存累计结果，初始值为 `0`。每遍历一种商品，就加上这件商品的小计。

### 本地存储

保存使用的键名是 `day-20-cart`，与其他练习的购物车分开。

```text
保存：cart → JSON.stringify() → localStorage.setItem()
读取：localStorage.getItem() → JSON.parse() → 检查数据 → cart
```

页面打开时先执行 `readCart()`，再执行 `renderCart()`，最后请求商品。即使商品接口请求失败，已恢复的购物车仍可修改和删除。

保存和读取使用 `try / catch` 做基本保护。保存失败时显示提示，购物车仍可在当前页面操作；读取失败或数据格式不正确时，本次从空购物车开始。读取失败不会立即覆盖原存储，下次修改购物车时才写入新数据。

## 5. 检查本地数据

在浏览器开发者工具中打开 Application → Local Storage，选择当前站点，找到 `day-20-cart`，检查保存的商品 ID、名称、单价和数量。

也可以在 Console 中执行：

```js
JSON.parse(localStorage.getItem('day-20-cart'))
```

购物车只保存在当前浏览器的当前站点中。更换浏览器、端口或在 `localhost` 与 `127.0.0.1` 之间切换时，不会共享这份存储。清理站点数据也会删除购物车。
